This supplements V3_SCORELESS_OWNER_AMENDMENT_v1.1.0 within the existing FSM,

It overrides the preceding amendment's retention of physical per-symbol cooldowns.

## Opportunity and attention

- A rejected or internally accepted OPEN closes that opportunity identity, not
  the symbol. No physical same-symbol cooldown applies. Distinct new eligible
  setups can start before an earlier study/trade horizon ends.
- The first accepted PRE starts one persisted 120-second attention window for
  that symbol. A new symbol cannot enter focus during that window. Existing
  accepted chains may continue. Same-symbol PRE does not extend an active window.
- This is an operational attention rule, never a market-quality filter. Every
  newly admitted setup still passes the complete fresh physical gates.
- Exact closed-identity/stage replay stays suppressed across restart. A new
  candle or direction creates a distinct setup identity through existing rules;
  no timer alone manufactures a market opportunity.
- Preserve fast focus for the same symbol until its existing lease expires.
  Closed ideas can give up focus capacity to a new eligible symbol; active ideas
  cannot be replaced by a score. Capacity remains two symbols.
- Retire persisted physical cooldown timers on upgrade; retain their terminal
  identities and historical evidence. No prior event or receipt is reconstructed.

## Visible signal contract

Stable reading order: stage and meaning; symbol and direction; analysis timeframe
and issue time with timezone; reference price; buffer with units and plain meaning;
stage-appropriate timing; required next action; stable opportunity ID.

PRE means watch; CONFIRM means prepare and wait. Neither claims entry readiness.
CONFIRM shows the governed expiry interval only when available. OPEN_NOW shows
the exact governed duration from actual entry, never Model Time as execution expiry.
Missing calibration is explicitly unavailable. V3 displays no score, TPS, invented
win probability or guaranteed profit. The buffer is a movement margin, not a win
guarantee. Detailed physics/audit remain in authorized explanation surfaces.

Private OPEN_NOW STUDIU remains explicitly simulated with real observed quotes
and unvalidated study duration. Its result separates direction and buffer. It is
never counted as canonical publication or broker execution. Figma examples must
be labelled as examples; a valid-expiry mockup is not evidence of live calibration.

## Ten-minute observational sequences

Group prospective accepted-chain studies per symbol in fixed half-open windows
of 600 seconds from the first observed entry. Report first, second, third and later
positions, exact sample counts and WIN/LOSS/DRAW/UNKNOWN/PENDING separately.
Keep overlaps visible and outside the existing independent calibration cohort.
An observation counts as after a loss only if the prior loss quote was available
before that next entry; no look-ahead. These descriptive comparisons cannot select
signals, change calibration, raise stakes, or prove recovery after a loss.
